把 M3 的 15 张图放在这个目录下。

推荐命名格式：

- `metal-anxiety-1.png`
- `metal-joy-1.png`
- `metal-calm-1.png`
- `water-anxiety-1.png`
- `water-joy-1.png`
- `water-calm-1.png`
- `wood-anxiety-1.png`
- `wood-joy-1.png`
- `wood-calm-1.png`
- `fire-anxiety-1.png`
- `fire-joy-1.png`
- `fire-calm-1.png`
- `earth-anxiety-1.png`
- `earth-joy-1.png`
- `earth-calm-1.png`

支持扩展名：`png`、`jpg`、`jpeg`、`webp`。

同一组合可放多张版本，文件名后缀可用：

- `-1` 到 `-5`
- `_01` 到 `_05`
- `-a`、`-b`、`-c`

页面会按候选顺序自动尝试加载，加载失败会切换到下一个候选。

你当前这套图（熊 / 凤凰 / 狐狸 / 鱼 / 鹿）可直接按下面命名：

- 熊（土）: `earth-anxiety-1.png`、`earth-joy-1.png`、`earth-calm-1.png`
- 凤凰（火）: `fire-anxiety-1.png`、`fire-joy-1.png`、`fire-calm-1.png`
- 狐狸（金）: `metal-anxiety-1.png`、`metal-joy-1.png`、`metal-calm-1.png`
- 鱼（水）: `water-anxiety-1.png`、`water-joy-1.png`、`water-calm-1.png`
- 鹿（木）: `wood-anxiety-1.png`、`wood-joy-1.png`、`wood-calm-1.png`
